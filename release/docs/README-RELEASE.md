# Memory Atlas v0.1.0-alpha.1 — 安装与使用（Windows Portable）

> **Alpha 说明**：这是开发者预览版。它不是人脑模拟，不是自动记忆精灵；它是一个
> 带纠正链与来源的记忆服务 + 一个桌面工作台。20GB 规模未验证；真实模型兼容情况
> 以实测为准（见 `VERIFY.md`）。Windows 构建未签名，首次运行 SmartScreen 会提示
> "更多信息 → 仍要运行"。

## 安装

1. 把整个 ZIP 解压到**任意**目录（支持中文与空格路径）。
2. 双击 `MemoryAtlas.exe`。没有第 2 步。

- 不需要安装 Node 或 npm（运行时已随包携带：`resources\app\runtime\node.exe`）。
- 不需要 `npm install`。
- 数据**不会**写入解压目录；见下文"数据在哪"。

## 数据在哪

| 内容 | 位置 |
|---|---|
| 正式记忆数据（默认） | `%APPDATA%\Memory Atlas Alpha\atlas-data\` |
| 桌面端配置 | `%APPDATA%\Memory Atlas Alpha\config.json` / `state.json` |
| 自定义数据目录 | 启动参数 `--data-dir <目录>` |

备份 = 备份数据目录。卸载 = 删解压目录 + 删上面的数据目录。

## 界面导览

- **查（查找）**：检索当前有效记忆；可切换"当前有效 / 全部历史 / 已被更新 / 已撤回"四个效力视角。
- **管（管理）**：写入（"记住这段内容"）、纠正、撤回；每次操作都有回执。
- **维（维护）**：检索索引状态；索引不可信时这里会如实显示，检索自动降级到权威扫描。
- **宇（宇宙）**：记忆关联视图（实验性）。
- **记忆对话实验**：接一个 OpenAI-compatible 模型后，可在对话里引用记忆（实验性）。

## 检索怎么用

词法检索：命中靠词项（中文一元/二元 + ASCII 词），多个词按 AND 组合。
**不做同义改写**：搜「约定」搜不到「答应」——搜不到时它说 `没有匹配的记录`，不猜。

## 让其他 Agent 用你的记忆（MCP）

先启动桌面程序（它拥有 Atlas 服务），再按 `MCP-GUIDE.md` 把 DSH / MaiBot /
任何 MCP 客户端接到同一个服务。MCP 工具默认**只读**；不存在自动记忆捕获。

## 程序关闭与进程

关闭窗口即退出；Atlas 服务子进程随之优雅停止（数据落盘、`endpoint.json` 移除）。
双开被阻止：第二个实例会自动退出。关闭后没有孤儿进程。

## 已知限制

- 检索为词法级，无同义桥（见上）。
- 20GB 规模未验证；容量参数是配置值不是实测结论。
- 未签名发行：无法校验发布者身份，SmartScreen/杀软可能提示。
- "宇宙"视图与激活/强化相关功能属实验性。
- 记忆对话实验需要你自己配置模型（API Key 只保存在本机配置中，仅主进程持有）。
